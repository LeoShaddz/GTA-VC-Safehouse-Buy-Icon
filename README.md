# GTA Vice City Safehouse Buy Icon

This mod adds icons for purchasable safehouses to the minimap and map. It does not include icons for assets, as Silent Patch already handles that.

Demonstration: https://i.imgur.com/wlLqV5S.jpeg

If you encounter any issues or instability, feel free to contribute or even create your own version if you can improve upon this one. Sorry for any problem.
